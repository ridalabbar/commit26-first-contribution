# Contributing to the COMMiT '26 Lab

Thank you for contributing. This repository is a learning space, so questions and small mistakes are welcome.

## Required lab: create your participant file

### 1. Open the participants folder

From the repository homepage, open the `participants` folder.

### 2. Create a new file

Select **Add file → Create new file**.

Name the file using your GitHub username:

```text
your-github-username.md
```

Use lowercase letters and hyphens. Do not add spaces.

### 3. Add your introduction

Copy this template and replace the example values:

```md
# Your name

- **GitHub:** @your-username
- **From:** Your city or country
- **Learning:** One technology or open-source topic
- **Contribution:** My first COMMiT '26 pull request
```

Only include information you are comfortable sharing publicly.

### 4. Create a branch and commit

Choose **Create a new branch for this commit and start a pull request**.

Use a clear branch name:

```text
add-your-github-username
```

Suggested commit message:

```text
Add @your-username to participants
```

### 5. Open the pull request

Suggested title:

```text
Add @your-username to participants
```

In the description, explain what changed and why. Mention the lab issue without closing it:

```text
## What changed

Added my participant introduction for the COMMiT '26 lab.

## Checklist

- [x] I created a new file in `participants/`
- [x] The filename uses my GitHub username
- [x] I reviewed the Files changed tab

Related to #1
```

### 6. Review your change

Before submitting, open **Files changed** and confirm:

- Only one new participant file is included.
- No private information was added accidentally.
- The preview looks correct.

### 7. Share your success

Create the pull request and paste its link into the session chat.

## Reviewing another participant

If you finish early, open another participant’s pull request and leave one helpful comment. Good feedback is:

- Kind
- Specific
- About the change, not the person
- Easy to act on

Example:

> Nice first contribution! The filename and formatting both match the guide.

## Need help?

Ask in the online session chat and include the step where you became stuck. A screenshot is useful, but never share passwords, access tokens, or private account information.
