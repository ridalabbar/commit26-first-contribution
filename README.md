# COMMiT '26 — First Contribution Lab

Welcome! This is a friendly practice repository for the session **Why open source contribution matters, and how to make your first one**.

You do not need to install anything. The required lab can be completed entirely on the GitHub website.

## Your mission

Create one new Markdown file inside [`participants/`](participants/) and open a pull request.

Use this filename:

```text
participants/your-github-username.md
```

Use this content:

```md
# Your name

- **GitHub:** @your-username
- **From:** Your city or country
- **Learning:** One technology or open-source topic
- **Contribution:** My first COMMiT '26 pull request
```

Follow the complete [contribution instructions](CONTRIBUTING.md).

## What you will practise

- Reading a repository and its contribution guide
- Creating a focused change
- Working on a new branch
- Writing a clear commit message
- Opening and reviewing a pull request
- Responding positively to feedback

## The project

The repository includes a tiny static “Contribution Wall” website. It is intentionally simple so beginners can explore real project files without a build process or dependencies.

Open [`index.html`](index.html) to see the page structure, [`styles.css`](styles.css) for the design, and [`script.js`](script.js) for the small interaction.

## Optional challenges

Finished early? Choose one small improvement:

- Improve one sentence in the documentation.
- Add an Arabic translation of the welcome message.
- Suggest an accessibility improvement as an issue.
- Review another participant’s pull request constructively.
- Add a useful beginner-friendly open-source resource.
